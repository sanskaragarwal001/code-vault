# Rust

Rust is a modern systems programming language focused on performance, reliability, and memory safety.

Today, Rust is used in operating systems, browsers, databases, networking, software, embedded systems, cloud infrastructure and high-performance backend services.

## Why Rust Exists

Programming languages have traditionally made a trade-off between performance and safety.

Languages like **C** and **C++** provide direct control over memory and system resources, making them extemely fase. However, this control comes with the risks such as:

- Memory leaks
- Dangling pointers
- Buffer overflows
- Data races in concurrent programs

On the other hand, languages such as **Java**, **C#**, **Go** and **Python** improve safety and developer productivity through garbade collection and runtime checks. While this reduces many classes of bugs, it introduces additional runtime overhead and less direct control over memory.

Rust was designed to provide both:

- Performance comparable to C and C++
- Memory safety without a garbage collector
