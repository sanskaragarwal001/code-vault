# Code Vault

A personal knowledge repository documenting my journey through programming, computer science, and software engineering.

The goal of this repository is not to collect snippets or solutions, but to build a structured understanding of concepts by writing them down in my own words.

## Purpose

Learning something once is easy.

Remembering it months later is difficult.

This repository serves as a long-term knowledge base where I document:

* Programming language concepts
* Personal notes and insights

Writing concepts from first principles helps reinforce understanding and exposes gaps in knowledge that may otherwise go unnoticed.

## Philosophy

Most learning resources focus on *how* to use a feature.

This repository focuses on:

1. Why the feature exists
2. What problem it solves
3. The mental model behind it
4. The rules that govern it
5. Practical examples

The objective is to understand concepts deeply enough to explain them clearly.

If I cannot explain a topic in simple terms, I probably do not understand it well enough.

## Repository Structure

```text
code-vault/
├── rust/
```

Each technology or subject is organized into dedicated directories containing notes, explanations, examples, and references.
